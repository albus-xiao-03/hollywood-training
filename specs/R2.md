# Following Specification - R2

Build fully `keyboard-driven-control` feature for package `hollywood-training`.

---

## Objective

Build a fully `keyboard-driven-control` nature for package `hollywood-training` replacing the `keyboard-mouse-hybrid-driven-control` nature of the package implementation for specification `R1`.

---

## Requirements
1. The mouse pointer **MUST NOT** be displayed **ANYWHERE** inside the `Hollywood Training` window.
2. **ALL** mouse-based interactions **MUST** be disabled within the application.
3. **ALL** implemented functionality **MUST** remain accessible and operational without mouse interaction.
4. Additional commands may be added to replace existing mouse-based interactions.
5. **ALL** other specified features by `R1` **MUST NOT** be affected.
6. The mouse pointer and mouse interactions **OUTSIDE** the `Hollywood Training` window **MUST NOT** be affected.
7. **ALL** keyboard input **MUST** be automatically rerouted to internal terminal inside the `Hollywood Training` window for interaction, **WHEN** users stay on the `Hollywood Training` window.
